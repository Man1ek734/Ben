# Ben Discord Bot

Bot Discord dla serwera `1566469722365493340`.

Wymagany Node.js 20 lub nowszy.

1. Uruchom `npm install`.
2. Skopiuj `.env.example` do `.env`.
3. Wpisz w `.env` token bota oraz Application ID z Discord Developer Portal. Nie udostępniaj tokenu ani nie dodawaj `.env` do GitHuba.
4. Zaproś bota do serwera, nadając mu zakresy `bot` i `applications.commands` oraz uprawnienia `View Channels`, `Send Messages`, `Manage Messages`.
5. Uruchom `npm start`.

Komendy: `/ping`, `/pomoc`, `/clear liczba`.

Bot musi pracować na uruchomionym komputerze lub hostingu; GitHub Pages nie uruchamia procesów Node.js.
